# SOCKS5 安全与性能加固

目标：在现有 CONNECT 代理和扩展接口基础上，修复可复现的安全问题，控制并发资源消耗，并提供可重复的验证。

采用 Go 标准库实现；库和命令行均使用安全默认值，无认证、PermitAll 和私网目标访问都必须显式开启。当前目录没有独立 Git 仓库，所有改动仅限本项目，不修改父目录仓库状态。

## 实施任务

- [x] 协议与认证：先复现非法保留字段、空域名、空认证字段、认证降级与短写；完整读取报文，校验字段，固定长度比较密码，按服务端优先级选认证方式。
- [x] 生命周期：握手 10 秒、DNS/拨号合计 10 秒、最多 1024 个客户端；连接关闭时释放额度；DNS 和 DialContext 接收可取消上下文；空闲超时可配置；转发错误关闭两端并等待两个复制任务结束。
- [x] 目标规则：增加公网目标规则，检查重写后的实际 IP，阻止私网、回环、链路本地、未指定、多播与常见非公网地址；拨号使用已校验的 IP，避免再次解析造成绕过。
- [x] 命令行：默认 127.0.0.1:8182，公网无认证需 -allow-no-auth；支持 SOCKS5_AUTH 或 -auth，避免必须把凭据放在命令行；密码保留冒号；添加超时、并发和内网开关；SIGINT/SIGTERM 关闭服务并收回连接。
- [x] 性能与依赖：迁移标准库 context，移除 x/net；使用复用的 32 KiB 缓冲区，并通过活动读取包装保留 io.Copy 的快速路径。
- [x] 文档与验证：动态端口替换固定端口，异步错误回到测试主协程；补真实 CONNECT/半关闭/超时/并发/关闭测试，运行完整测试、竞态检查、go vet、构建及基准测试。

## 验收边界

只支持 CONNECT，BIND/UDP ASSOCIATE 仍返回不支持。自定义认证、解析器、规则、拨号函数必须遵守并发与上下文约定。SOCKS5 用户名密码没有传输加密，远程部署通过 VPN/SSH/TLS 隧道保护。连接限制按 Server 实例计算；不引入全局 DNS 缓存，避免过期和无界缓存问题。
